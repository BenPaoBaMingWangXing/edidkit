# edidkit

`edidkit` is a MoonBit native toolkit for parsing and auditing EDID display identification data. It decodes monitor identity, checksum, version, basic display parameters, chromaticity coordinates, established timings, standard timings, detailed timing descriptors and monitor text descriptors.

Package: `BenPaoBaMingWangXing/edidkit`

## Scope

This project focuses on EDID base blocks and display timing diagnostics. It does not implement HTTP, multipart/form-data, subtitle parsing, license scanning, SBOM generation or operating-system display driver bindings.

## Status

The package is prepared for MoonBit hackathon validation with source code, tests, runnable examples, CI configuration, documentation, project proposal and Mooncakes metadata.
